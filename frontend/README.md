# PlantPerform frontend

The frontend is a React and TypeScript application built with Vite. From this
directory, install dependencies and start the development server with:

```bash
npm ci
npm run dev
```

The development server proxies `/api` to `http://localhost:8000`. Start the
backend first when working with live application data.

Run the frontend checks with:

```bash
npm run lint
npm run build
```
